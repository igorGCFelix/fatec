CASO DE USO EXPANDIDO

FLUXO PRINCIPAL DE SUCESSO:

Caso de uso: Consultar
1- O sistema exibe todas as médias e nomes dos alunos.

Caso de uso: Incluir
1- O usuário irá entrar com o nome e a média do aluno.
2- O sistema armazena os dados incluidos do aluno.
3- O sistema exibe uma imagem confirmando a inclusão do aluno

Caso de uso: Excluir
1- O sistema irá pedir o índice do aluno que deseja excluir.
2- O usuário digita o índice do aluno
3- O sistema mostra o nome e a média do aluno.
4- O sistema pergunta se deseja continuar com a exclusão
5- O usuário confirma a exclusão.
6- O sistema excluirá os dados do aluno escolhido.

Caso de uso: Alterar
1- O sistema irá pedir o índice do aluno que deseja alterar os dados.
2- O usuário escolhe o aluno que deseja alterar os dados.
3- O sistema apresenta o nome e média do aluno escolhido
4- O sistema pergunta se deseja continuar
5- O usuário confirma a continuação 
6- O sistema pede o nome que deseja alterar.
7- O usuário preenche o nome.
8- O sistema pede a média que deseja alterar.
9- O usuário preenche a média
10- O sistema pergunta se deseja continuar
11- O usuário confirma a alteração.
12- O sistema irá alterar os dados com os novos valores.

FLUXO ALTERNATIVO:

Caso de uso: Consultar
1a. Não há dados a exibir
    1. O sistema informa que não há alunos/notas a exibir.

Caso de uso: Incluir
1a. Nome e/ou média de aluno não informada.
    1. O sistema informa que o nome e/ou a média do aluno não foi informada.
    2. O sistema encerra o processo.
1b. Nome de aluno inválido (com algum algarismo)
    1. O sistema informa que o nome é inválido
    2. O sistema voltará a emitir a pergunta até que a condição do nome válido seja realizada
1c. Média de aluno inválida.
    1. O sistema informa que a média do aluno é inválida
    2. O sistema voltará a emitir a pergunta até que a condição da média válida seja realizada
1d. Média fora do intervalo permitido (0 até 10)
    1. O sistema informa que a média inserida está fora do intervalo permitido
    2. O sistema voltará a emitir a pergunta até que a condiçao da média seja atendida


Caso de uso: Excluir
2a. O índice citado não existe na lista
    1. O sistema informa que não há um aluno com esse índice
    2. O sistema encerra o processo.
2b. O índice digitado é inválido (caractere, número negativo, número em decimal, etc)
    1. O sistema informa que o índice fornecido é inválido.
    2 O sistema encerra o processo.
5a. O usuário digita (S/N) minúsculo para confirmar
    1. O sistema irá por meio do upper() deixar o valor inserido em caixa alterar
    2. O sistema irá prosseguir com a comparação
5b. O usuário digita (S)
    1. o sistema irá prosseguir com a exclusão
5c. O usuário digita (N)
    1. O sistema irá cancelar a exclusão e encerrar o processo
5d. O usuário digita um valor inválido dentre as opções
    1. O sistema emite uma mensagem de erro, falando da invalidez do valor inserido
    2. O sistema voltará a emitir a pergunta até que a condição de (S) ou (N) seja realizada
